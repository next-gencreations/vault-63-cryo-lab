# Vault 63 — Cryo Lab

  A Fallout-themed 3D first-person experience built with React Three Fiber,
  integrated with your AI crypto trading dashboard.

  ## Deploy to Vercel

  1. Import this repo in Vercel — it will auto-detect Vite
  2. No environment variables needed (API URL saved in-browser via localStorage)

  ## Connect your trading dashboard

  1. Enter the game and press **Tab** to open Pip-Boy
  2. Click the **₿ BOT** tab
  3. Click **SET DASHBOARD URL**
  4. Enter: `https://app.next-gencreations.com`
  5. Press Enter — data refreshes every 8 seconds

  ## Local dev

  ```
  npm install
  npm run dev
  ```
